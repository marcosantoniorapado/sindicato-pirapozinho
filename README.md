# Site institucional — Sindicato dos Servidores Municipais de Pirapozinho

Repositório do site institucional do Sindicato dos Servidores Municipais de Pirapozinho.

## Site publicado

**https://sindservpirapozinho.com**

O site é estático, construído com HTML, CSS e JavaScript, e publicado pelo GitHub Pages. O domínio institucional é definido no arquivo `CNAME`.

## Estrutura

- `index.html` — conteúdo e estrutura da página
- `assets/css/style.css` — estilos e responsividade
- `assets/js/script.js` — menu móvel
- `assets/img/` — imagens institucionais e materiais visuais

## Atualização

Faça as alterações em uma branch, revise localmente e aguarde aprovação antes de publicar no repositório remoto.
